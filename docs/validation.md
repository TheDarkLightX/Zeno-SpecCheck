# Validation of the recovered prototype and iterative feedback

The initial implementation was recovered from the prior workspace before its first GitHub publication. Its 44 tests were rerun against the real Tau runtime described in [tau-runtime.md](tau-runtime.md); all passed, including the four optional live tests.

An end-to-end check found a gap outside the old test suite: the documented 512-candidate exit example wrote a 1,707,649-byte JSON report, but replay used the same 1 MB input limit as project files. The new reader keeps a 1 MB limit for projects/proposals and a separate 64 MB limit for reports. It bounds the read itself. CI now replays the larger exit report and builds the follow-up request.

The continuation adds eleven tests covering:

- failed search → verified feedback → controlled external proposal → accepted repair → full replay;
- the full documented 512-candidate report and follow-up request;
- stale project/source identities, altered evidence, malformed provenance, and malformed search configuration;
- canonical comparison distinguishing JSON Booleans, integers, and floats;
- bounded witness feedback with explicit omissions and unchanged exhaustive acceptance;
- a passing current candidate alongside historical failures, with no invented human approval.

Final local result on 2026-10-02: **55 tests passed with no skips**, including the four real-Tau tests. The source digest in `evidence/pilot.json` identifies the tested package. GitHub Actions covers the reference and process-boundary workflow; the native runtime remains external.

Run the complete suite:

```bash
ZENO_TAU_PYTHON=/path/to/tau-venv/bin/python \
ZENO_TAU_MODULE_DIR=/path/to/tau/build/release/bindings/python/nanobind \
ZENO_TAU_REVISION=31b5b3cfa546d1769cb27c882f131a2914452b55 \
python -m unittest discover -s tests -v
```

Without the Tau environment variables, four live tests are explicitly skipped. The default GitHub Actions job runs the dependency-free tests and CLI workflows on Python 3.11, 3.12 and 3.13; it does not install Tau.

The pilot receipt is regenerated by `scripts/run_pilot.py`. It records the source manifest, unchanged illustrative repair results, the native Tau run, and the reduced runtime's full-LTL UNKNOWN result. It is a small scoped experiment, not a benchmark showing that evolution or learned ranking outperforms other search strategies. The controlled proposal test does not invoke or measure a neural model.
